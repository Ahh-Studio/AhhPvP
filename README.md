# AhhPvP

A Minecraft PvP Mod by Ahh Studio

<details open>
<summary>English</summary>

### Weapons
- Fireball — explosive, breaks blocks, with optional fire
- Bridge Egg — auto-placing bridge blocks
- BBU Fishing Rod
- BBU Sword
- Bed Bug
- Axe of Murder
- Return Scroll
- BuildUHC Gear

### Tools & Utilities
- Rescue Platform — configurable cooldown & vanish time (game rules)
- Invisibility Potion (water bottle + glass, brewing recipe, 30s)

### Blocks
- 16 colored tempered glass (stained strong glass)
- Auto TNT Igniter
- Custom Spawner

### Mechanics
- Sword Blocking — no knockback reduction
- Custom fireball explosion
- Custom game rules

### Technical

```
MOD_ID: pvp
package: com.aiden.pvp
```

### 武器
- 烈焰弹 — 可爆炸，破坏方块，可选择是否产生火焰

- BBU 剑
- 床虱
- 秒人斧（谋杀之斧）

- 救援平台 — 可配置冷却时间和消失时间（游戏规则）
- 隐形药水（水瓶 + 玻璃，酿造配方，30s）

- 16 种颜色的钢化玻璃（染色钢化玻璃）
- 自动 TNT 点燃
- 自定义刷怪笼

- 剑格挡 — 不会减少击退效果

- 自定义游戏规则
