# AhhPvP

A Minecraft PvP Mod by Ahh Studio · v1.4.6 (Minecraft 26.1.2, Fabric / NeoForge)

<details open>
<summary>English</summary>

### Platforms
- Fabric and NeoForge, built from a single shared `common` source tree

### Weapons
- Fireball — explosive, breaks blocks, with optional fire
- Bridge Egg — auto-placing bridge blocks
- BBU Fishing Rod
- BBU Swords (wooden / stone / iron / diamond)
- Bed Bug
- Axe of Murder
- Return Scroll
- Throwable Dagger

### Tools & Utilities
- Rescue Platform — configurable cooldown & vanish time (game rules)
- Invisibility Potion (water bottle + glass, brewing recipe, short & long)
- Runes — Carbon Rune, Iron Rune, Boss Key, BBU Upgrade Smithing Template

### Blocks
- 16 colored tempered glass (stained strong glass)
- Auto TNT Igniter / Throwable TNT
- Boss Spawner
- Landmine
- Defense Tower
- Golden Head

### Mobs
- Murderer — a PvP boss with player-like combat AI (melee, dagger, fireball, ender pearl, block mining, golden apple healing)

### Technical

```
MOD_ID: pvp
package: com.aiden.pvp
```
